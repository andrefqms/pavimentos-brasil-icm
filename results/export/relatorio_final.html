Artefatos de Deployment

  • ONNX pavimentos_yolov8.onnx — deployment multiplataforma (OpenCV, ONNX Runtime, TensorRT)
  • PT pavimentos_yolov8_best.pt — pesos originais PyTorch (ultralytics)
  • TS pavimentos_yolov8_torchscript.torchscript — inferencia CPU/mobile otimizada
  • JSON model_metadata.json — metadados do modelo (classes, thresholds, metricas)
  • ZIP pacote_deploy.zip — todos os artefatos empacotados

Como Usar o Modelo (ONNX)

from ultralytics import YOLO
import json, pathlib

# Carrega metadados
meta = json.loads(pathlib.Path('model_metadata.json').read_text())
print('Classes:', meta['classes'])
print('mAP50:', meta.get('mAP50', 'N/A'))

# Inferencia com ONNX
model = YOLO('pavimentos_yolov8.onnx')
results = model.predict('imagem.jpg', conf=0.25, iou=0.45)
results[0].show()          # visualizar
results[0].save()          # salvar imagem anotada
